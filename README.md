I've been building my home cockpit around the A320 and, like many of you, I'm using tablets/screens for EFBs and other simulator interfaces.

And there was one thing that kept annoying me:

**Why am I still using a browser for something that is supposed to be a cockpit display?**

Open Chrome/Edge → type IP → type port → deal with browser UI → fullscreen → zoom → resize → repeat.

So… I got annoyed enough to build my own solution. 😂

### 🚀 Meet EFB AVIONICS SUITE

It's a small Android app that turns an Android device into a dedicated fullscreen display for **web-based simulator interfaces**.

You simply enter:

**IP address + Port → Connect**

…and that's it.

No browser.
No address bar.
No browser buttons.
No unnecessary UI.

Just the remote interface, fullscreen, ready to become part of your cockpit.

### 🛫 And it's not limited to one EFB

I originally built it for my **Fenix A320 EFB**, but I deliberately designed it to be generic.

If your simulator software exposes a web interface through an IP address and port, the app can potentially display it.

I've already been testing it with different EFB implementations and things such as **GSX Pro**.

So the idea isn't:

> "An app for the Fenix EFB."

It's more:

> **"A dedicated Android client for simulator web interfaces."**

### 🖥️ Perfect for cockpit builders

The whole idea is to take an inexpensive Android tablet/phone and turn it into a dedicated cockpit screen.

Think:

📱 Android tablet
⬇️
🌐 IP + Port
⬇️
✈️ Fullscreen simulator interface

No need to keep a browser open or manually configure it every time.

### 🔧 What it currently does

• Fullscreen WebView
• IP + port configuration
• Designed for cockpit/tablet use
• Works over your local network
• No browser UI
• Supports different web-based simulator interfaces
• Designed to work independently from the simulator itself

And I'm currently working on making it even more useful for cockpit setups.

For example, I'm considering a proper launcher where you could have:

**FENIX EFB**
**GSX PRO**
**OTHER EFB**
**CUSTOM WEB INTERFACE**

Tap one → connect → fullscreen.

Basically a small **EFB Hub** for the cockpit.
